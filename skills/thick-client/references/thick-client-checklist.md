# Thick Client Checklist

- [ ] Check installation or uninstall residue and permissions.
- [ ] Check automatic startup and services.
- [ ] Check credential storage (DPAPI, Keychain, or plaintext).
- [ ] Check the update URL and signature verification.
- [ ] Check certificate pinning and proxy compatibility.
- [ ] Check hidden features and debug menus.
- [ ] Check local ports bound to 0.0.0.0.
